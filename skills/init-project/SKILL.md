Set up the foundations of a brand-new project. Assume most things are still unknown; that's fine.

Work in `/concise` mode throughout.

1. Vision: `/grill-me` on the core problem, users, and what's out of scope. "Don't know yet" is a valid answer: record it, move on.
2. Domain: `/craft-domain` to create a first `DOMAIN.md`. A thin glossary and one context is enough; unknowns go to Open questions.
3. Scaffold: `README.md`, `CLAUDE.md` pointing to `DOMAIN.md`. Add a stack or folder layout only if already decided.

Finish and confirm each phase before the next. Don't fill gaps with guesses.
